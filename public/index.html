Overview

Everything you need to ship a CV

A focused builder — no accounts, no drag-and-drop maze. Fill structured fields, preview on real A4 layouts, and save locally on your machine.

◫

Structured editor

Personal info, summary, experience, projects, education, skills, and certifications — organized in tabs, not scattered text boxes.

⇄

Template switching

Change layout from the toolbar without re-entering data. Your template choice is stored alongside your CV in SQLite.

⎙

Print to PDF

Layouts are tuned for A4. Use Print / Save PDF in the builder for a file recruiters and ATS-friendly workflows expect.

Templates

Three distinct visual identities

Same content, different personality — sidebar classic, Scandinavian minimal, or editorial bold. Pick what fits your industry and taste.

Classic Sidebar

Dark sidebar, warm accents, EB Garamond headings — timeless for tech and corporate roles.

Nordic Minimal

Strong header band, dot skills, restrained typography — clean and modern without noise.

Editorial Bold

Magazine-style hero, amber highlights, split columns — for creatives and senior profiles.

Workflow

Up and running in minutes

Run locally with Node.js. Your data stays in a SQLite file under data/cv.db.

Install & start

npm install then npm start — open localhost:3000.

Open the builder

Click Open builder to edit your CV with live preview.

Edit & save

Apply changes from the modal; everything syncs to the database automatically.

Export

Switch templates anytime, then print to PDF when you are happy with the result.
